# E-Commerce Sales Analytics

## Project Overview
This project analyzes online retail transaction data to identify sales trends, top-performing products, customer purchasing behavior, and geographical revenue distribution.

The goal is to extract meaningful business insights from transactional data using Python, Pandas, data visualization, and SQL.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SQLite / SQL
- Jupyter Notebook

## Dataset
The project uses the Online Retail dataset containing transactional data from a UK-based online retail business.

Dataset Source: UCI Machine Learning Repository – Online Retail Dataset.

## Analysis Performed
- Sales performance analysis
- Monthly revenue trends
- Top products by quantity sold
- Top products by revenue
- Country-wise revenue analysis
- Top customer analysis
- Repeat vs one-time customer analysis
- SQL-based business analysis

## Key Findings
- Total revenue: £10.64 million
- Total orders: 19,960
- Identified customers: 4,338
- Repeat customer rate: 65.58%
- United Kingdom contributed approximately 84.59% of total revenue.
- November 2011 recorded the highest monthly revenue.

## Business Recommendations
- Maintain inventory of high-demand products.
- Develop customer retention strategies to encourage repeat purchases.
- Explore opportunities to expand sales in international markets.
- Analyze high-revenue products and customer segments to improve profitability.
